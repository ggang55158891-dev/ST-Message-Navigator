# H-01 실제 SillyTavern 최소 실사용 점검표

이 문서는 **테스트 시나리오**다. GitHub Actions의 모의 ST 통과가 실제 서버와 다른 확장들의 동시 호환성을 증명하지는 않는다.

## 준비

- 사용 중인 중요한 채팅의 **원본 JSONL ZIP**, 확장 관리 설정 JSON, 표지 통합 ZIP을 별도로 보관한다.
- 먼저 **새 테스트용 캐릭터/그룹 및 짧은 시험용 채팅**으로만 진행한다. 실제 작업 채팅에서는 삭제/순서 변경을 시험하지 않는다.
- 확장 설정 → 엘리베이터 → 오류 진단 및 내보내기 → **사용 환경 점검(읽기 전용)**을 실행한다. '추가 확인'은 기능 미지원 *가능성*을 뜻하며, '인터페이스 확인'은 실제 저장·네트워크 통신 성공을 보증하지 않는다.

## 최소 검증: PC 한 대에서 10~15분 내 핵심만

| 순서 | 사용자 동작 | 확인할 결과 |
|---|---|---|
| 1 | 층 안내 열기, 처음/이전/다음/마지막 이동 | 메시지 #위치가 맞고 중간에서 건너뛰지 않음 |
| 2 | 상단 돋보기에서 현재/전체 검색, 검색 결과 클릭 | 위치 정확, 결과를 닫으면 기존 화면으로 복귀 |
| 3 | 시험용 메시지 제목·즐겨찾기·숨김 변경 후 채팅 전환/재시작 | 원본 메시지 본문 불변, 관리 정보가 보존됨 |
| 4 | 스와이프가 여러 개인 테스트용 메시지에서 비교·즐겨찾기·선택 | 올바른 답변이 선택되고 다른 답변/화자가 바뀌지 않음 |
| 5 | 시험용 채팅 별명·설명·폴더·표지 등록 후 재시작 | 데이터·이미지·연결 상태가 보존됨 |
| 6 | 테스트용 채팅 복제, 백업 ZIP, 복구본 조회 | 원본 무수정, 복제본/복구본 별개로 확인됨 |
| 7 | 테스트용 채팅 1개의 순서 변경 및 삭제 | 원본 ZIP 보관, 요청한 메시지만 변경, 서버 저장·재열기 결과 확인 |

## 외부 확장과 충돌 여부

같은 시험용 채팅에서 최적화 확장 및 **Cut & Paste**가 꺼진 상태와 켜진 상태를 비교한다. 메시지 이동/복사 뒤의 사용자 제목·북마크·스와이프, 재검색 위치가 유지되는지 확인한다. 문제가 발생하면 테스트를 중단하고 진단 JSON과 재현 순서만 기록한다. **원문 대사를 진단 보고서에 포함하지 않는다.**

## 판정

- API 점검 통과만으로 배포 안정성 완료를 선언하지 않는다.
- 시험용 채팅에서라도 원본/별도 관리 정보의 예상 밖 변경이 확인되면 해당 파괴 작업은 배포 보류.
- 실제 ST release/가능하면 staging, Windows Chrome 및 모바일, 그룹/캐릭터에서 최소 한 번씩 확인한 다음 정식 배포 후보를 판단한다.
